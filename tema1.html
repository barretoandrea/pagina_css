TEMA 02.1

Estructura y sintaxis de CSS

Antes de comenzar a diseñar una página web, es importante conocer cómo funciona CSS y cómo se escriben sus reglas.

¿Qué es CSS?

CSS significa Cascading Style Sheets, que en español se traduce como hojas de estilo en cascada. Es un lenguaje que se utiliza para darle diseño y apariencia a las páginas web.

Mientras HTML se encarga de organizar el contenido, como los títulos, párrafos, imágenes y botones, CSS permite cambiar la forma en que se muestran esos elementos.

Con CSS podemos modificar diferentes características:

Colores

Modificar el color del texto y los fondos.

Tipografía

Cambiar el tipo y tamaño de letra.

Tamaños

Modificar el ancho y alto de los elementos.

Distribución

Organizar la posición de los elementos.

¿Para qué sirve CSS?

Su función principal es separar el contenido de una página web de su presentación visual. Esto permite tener documentos HTML más organizados y cambiar el diseño sin modificar toda la estructura.

¿Cómo se escribe una regla CSS?

Una regla CSS está formada por un selector y un bloque de declaraciones. Las declaraciones se escriben entre llaves y cada una contiene una propiedad y un valor. 

h1 {
    color: purple;
    font-size: 30px;
    text-align: center;
}

Partes de la regla

Selector

Es el elemento HTML que queremos modificar. En el ejemplo, el selector es h1.

Propiedad

Indica qué característica se va a cambiar, como color, tamaño o alineación.

Valor

Indica cómo queremos que quede la propiedad, por ejemplo purple o 30px.

Los dos puntos separan la propiedad de su valor, y el punto y coma indica el final de una declaración.

Tipos de selectores básicos

Los selectores permiten elegir los elementos HTML a los que queremos aplicar estilos.

Selector Ejemplo Función
Elemento p Selecciona todos los párrafos.
Clase .titulo Selecciona elementos con esa clase.
ID #principal Selecciona el elemento con ese ID.
Universal * Selecciona todos los elementos.

Ejemplo de selectores

/* Selector de elemento */
p {
    color: blue;
}

/* Selector de clase */
.destacado {
    background-color: pink;
}

/* Selector de ID */
#principal {
    font-size: 25px;
}

Ejemplo práctico

Primero tenemos un documento HTML con un título y un párrafo. Después aplicamos CSS para cambiar sus colores, tamaños y presentación.

Código HTML

<p>Estoy aprendiendo CSS.</p>

Código CSS

h1 {
    color: #8068a8;
    text-align: center;
}

p {
    color: #695c70;
    font-size: 17px;
}

Conclusión

CSS permite darle estilo a los documentos HTML. Para escribir sus reglas necesitamos un selector, una propiedad y un valor. Con estos elementos podemos comenzar a personalizar cualquier página web.
