TEMA 02.2

Tipos de incorporación CSS

Existen diferentes maneras de aplicar estilos a una página web. Conoce las tres formas principales y aprende cómo funciona cada una.

¿Qué significa incorporar CSS?

Incorporar CSS significa agregar los estilos que necesita una página HTML para modificar su apariencia. Estos estilos pueden escribirse dentro del mismo documento HTML o en un archivo separado.

Existen tres formas principales de hacerlo: CSS interno, CSS externo y CSS en línea. Aunque las tres permiten cambiar el diseño, su manera de escribirse y organizarse es diferente.

Interno

Los estilos están dentro del HTML.

Externo

Los estilos están en otro archivo.

En línea

Los estilos están en la etiqueta HTML.

PRIMER TIPO

1. CSS interno

El CSS interno consiste en escribir los estilos directamente dentro del documento HTML. Para utilizarlo se emplea la etiqueta <style>, que normalmente se coloca dentro de la sección <head>.

De esta manera podemos tener la estructura HTML y los estilos en un mismo archivo, sin necesidad de crear un documento CSS independiente.

¿Cómo se utiliza?

<!DOCTYPE html>
<html>
<head>

    <title>Ejemplo CSS interno</title>

    <style>
        h1 {
            color: purple;
            text-align: center;
        }

        p {
            font-size: 18px;
        }
    </style>

</head>

<body>

    <h1>Hola, estoy aprendiendo CSS</h1>
    <p>Este es un ejemplo de CSS interno.</p>

</body>
</html>

¿Qué está pasando en el código?

Primero se escribe la estructura básica del HTML. Después, dentro de head, se abre la etiqueta style. Allí se escriben las reglas CSS que van a modificar los elementos de la página.

  • El título h1 cambia a color morado.
  • El título queda alineado en el centro.
  • El párrafo utiliza un tamaño de 18 píxeles.

Hola, estoy aprendiendo CSS

Este es un ejemplo de CSS interno.

Ventaja: es sencillo de utilizar cuando trabajamos con una sola página y queremos tener todo el código en el mismo documento.
SEGUNDO TIPO

2. CSS externo

El CSS externo consiste en escribir los estilos en un archivo independiente que tiene la extensión .css. Luego, este archivo se conecta con el documento HTML mediante la etiqueta link.

Es una de las formas más utilizadas en el desarrollo web porque permite separar el contenido de los estilos. Así, el HTML queda encargado de la estructura y el CSS se encarga de la apariencia.

¿Cómo se organiza?

Carpeta: mi-proyecto
index.html
styles.css

Código HTML

En el documento HTML se utiliza la etiqueta link dentro de head para conectar el archivo CSS. 

<!DOCTYPE html>
<html>
<head>

    <title>Ejemplo CSS externo</title>

    <link rel="stylesheet" href="styles.css">

</head>

<body>

    <h1>Mi primera página</h1>
    <p>Estoy utilizando CSS externo.</p>

</body>
</html>

Código del archivo styles.css

En este segundo archivo se escriben las propiedades y los valores que queremos aplicar. 

h1 {
    color: purple;
    text-align: center;
}

p {
    color: gray;
    font-size: 18px;
}

¿Qué está pasando?

El archivo HTML está conectado con styles.css. Por eso, cuando se abre la página, el navegador también lee las reglas que están escritas en el archivo externo y las aplica a los elementos.

Mi primera página

Estoy utilizando CSS externo.

Ventaja: permite reutilizar los mismos estilos en varias páginas y facilita el mantenimiento del proyecto.
TERCER TIPO

3. CSS en línea

El CSS en línea se aplica directamente a una etiqueta HTML mediante el atributo style. A diferencia del CSS interno y externo, no se necesita crear un bloque de estilos aparte.

Cada propiedad se escribe dentro del atributo style, junto con su valor. Es una forma rápida de modificar un elemento específico.

¿Cómo se utiliza?

<h1 style="color: purple; text-align: center;">
    Hola mundo
</h1>

<p style="font-size: 18px; color: gray;">
    Este texto tiene CSS en línea.
</p>

¿Qué está pasando?

En el primer ejemplo, el título tiene un color morado y está alineado al centro. En el segundo, el párrafo tiene un tamaño de 18 píxeles y un color gris.

Hola mundo

Este texto tiene CSS en línea.

Desventaja: si se utiliza en muchos elementos, el HTML puede volverse difícil de leer y mantener.

Comparación de los tres tipos

Aunque las tres formas permiten aplicar estilos, existen diferencias en la manera de organizar y escribir el código.

Tipo Dónde se escribe Característica
Interno Dentro de style en HTML. Los estilos están en el mismo documento.
Externo En un archivo .css. Permite reutilizar estilos.
En línea Dentro del atributo style. Modifica directamente un elemento.
Para tener en cuenta: el CSS externo suele ser la opción más organizada para proyectos con varias páginas. El CSS interno puede servir para documentos pequeños y el CSS en línea para cambios puntuales.

Conclusión

Los tres tipos de incorporación CSS permiten modificar la apariencia de una página web. La diferencia está en dónde se escriben los estilos y cómo se organizan. Elegir uno depende del tamaño del proyecto y de la forma en que queremos mantener nuestro código.
